GitHub Token
Dine data gemmes som en privat GitHub Gist og kan hentes på alle dine enheder. Du skal bruge et Personal Access Token fra GitHub med gist-rettighed.
Sådan opretter du et token
1. Gå til github.com → Settings → Developer settings
2. Vælg Personal access tokens → Tokens (classic)
3. Klik Generate new token (classic)
4. Sæt flueben ved gist
5. Klik Generate token og kopiér det
